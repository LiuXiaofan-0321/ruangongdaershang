# 大二上课程资料

本仓库同步本学期的八个课程文件夹：操作系统、操作系统lab、概率论与数理统计、高端软件开发方法、计算机网络、计算机网络lab、密码与网络安全导论、软件质量分析。

不包含往期资料、科研训练及项目。`计算机网络lab/lab1.pcapng` 超过 100 MiB，仅保留在原电脑。缓存、临时输出、操作日志和环境配置也不上传。Git 不保存空目录；“高端软件开发方法”加入文件后会自动出现。

## 在另一台电脑使用

1. 安装 [Git for Windows](https://git-scm.com/download/win)，并安装 GitHub Desktop 登录有本仓库写入权限的 GitHub 账号。
2. 将本仓库克隆到本地，例如 `C:\University Courses`。如果这个目录已经有资料，先克隆到一个新的空文件夹，避免覆盖已有文件。
3. 在新克隆的文件夹中工作。首次先用 GitHub Desktop 推送一次，确认本机已经完成 GitHub 登录并能正常推送。
4. 打开仓库的 `.course-sync` 文件夹，双击“启用自动同步.cmd”。每台电脑分别启用一次。
5. 双击“立即同步.cmd”可手动同步并查看结果。

## 自动同步如何运行

- 当前用户登录后运行，并每 10 分钟检查一次；电脑需开机、联网。
- 自动保存课程文件修改，下载另一台电脑的更新，并上传到 GitHub。删除已跟踪文件也会同步。
- 两台电脑不必同时开机，但换电脑前建议立即同步一次，并确认成功。
- 同一份 Word、PPT、PDF 尽量在一台电脑编辑完、同步成功后，再换另一台电脑。
- 遇到无法自动合并的冲突会停止本次同步，保留已提交的本地修改；不会强制推送或覆盖冲突文件。需要手动处理后才可继续同步。
- 新增未排除且超过 100 MiB 的文件时会停止，并写入日志；请先将它的路径加入 `.gitignore`。
- 日志位于本地 `.git/course-sync.log`，不上传到 GitHub。任务计划程序中的名称为 `UniversityCourses-GitHub-Sync-ruangongdaershang`，可在那里停用或删除。

仓库当前为公开仓库，上传内容可以被其他人查看。同步不替代独立备份。
