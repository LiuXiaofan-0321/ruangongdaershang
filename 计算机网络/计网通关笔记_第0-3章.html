零基础预备：单位、对数和三个比喻

算题丢分，八成是单位换算错。先把这页吃透。

b 和 B，k 和 K

bit（b）与 Byte（B）
小写 b = 比特（一个 0 或 1）；大写 B = 字节。
1 B = 8 b。网速用 bps（bit/s），文件大小用 B。
速率用 10 的幂
1 kbps = 10³ bps
1 Mbps = 10⁶ bps
1 Gbps = 10⁹ bps
存储用 2 的幂
1 KB = 2¹⁰ = 1024 B
1 MB = 2²⁰ B
1 GB = 2³⁰ B
时间
1 ms = 10⁻³ s
1 μs = 10⁻⁶ s
1 ns = 10⁻⁹ s
易错

“1 MB 文件用 1 Mbps 传要几秒？” 答案不是 1 秒，而是 2²⁰ × 8 / 10⁶ ≈ 8.39 s。考试若没说明，一般可以近似按 1 MB ≈ 10⁶ B 算（≈ 8 s），写清楚你的假设即可。

log₂ V 的意思是“V 是 2 的几次方”，也就是 V 种状态需要几位二进制来表示。

三个贯穿全课的比喻

寄快递 = 分层

你只管写信（应用层），快递员只管包装贴单（传输/网络层），货车只管把箱子运到下一站（链路/物理层）。每一层只和“隔壁层”打交道。

公路 = 信道

路宽 = 带宽（Hz），限速下最多能过的车 = 信道容量（bps），路的长度 = 传播时延。

打电话 vs 寄信 = 两种服务

打电话先拨通再说话（面向连接）；寄信直接投进邮筒，每封信各走各的（无连接）。

1.1 什么是计算机网络★★

课件定义：计算机网络是一组“自治的”计算机，通过同一种技术互相连接起来。

  • 自治（autonomous）：每台电脑自己就能独立计算，断网了也能用，不受别人控制。
  • 互连（interconnected）：它们之间能交换信息（文字、图片、音频、视频……）。

不同通信网络（电话网、电视网、计算机网）的区别：表面上看是终端不同，本质上是提供的服务不同。

考点 · 2023 选择第 1 题

“联网计算机必须使用统一的操作系统”是错误的。网络建立的主要目的是资源共享；多台机器可以协同完成任务；联网的电脑既能联网工作也能脱网工作（这就是“自治”）。

网络拿来干什么

商业
资源共享（打印机、云主机）、客户端-服务器模型
家庭
访问远程信息、人与人通信、交互娱乐、电子商务
移动
手机/平板 + WiFi 热点 + 4G/5G；GPS 等传感器
内容分发
同一视频发给很多人时，在网络里放副本（CDN），比每人从源头拉一份更省
直觉 · 统计复用

“复用”就是共享。用户大部分时间是空闲的，流量是一阵一阵的（突发）。所以不必给每人留一条专线，而是按大家实际需要动态分享带宽，这叫统计复用，是分组交换网（因特网）的基础。就像地铁不给每人留一节车厢。

社会问题（了解即可，可能出选择）：网络中立性；内容版权（美国 DMCA 1998，“通知-删除”）；匿名与审查（TOR 洋葱路由）；隐私（网页追踪，欧盟 GDPR 2018-05-25 实施）；盗窃（僵尸网络 botnet、网络钓鱼 phishing）。

1.2 网络硬件：连接方式与拓扑★★

两种连接方式（第一章自测第 4、5 题）：

  • 点到点（point-to-point）：两台设备之间一条专用链路。
  • 多点（multipoint）：两台以上设备共享同一条链路。

拓扑就是“设备怎么连成形状”。四种基本拓扑：

网状 Mesh
每两台都直连。
优：路径多、可靠。
缺：连线多（n 台要 n(n−1)/2 条）、端口受限、环路多易广播风暴。
星型 Star
所有设备连到中心集线器/交换机。
优：组网简单。
缺：中心坏了全瘫；中心端口数限制规模。
总线 Bus
大家挂在一根共享电缆上。
优：便宜、易扩展、单个节点坏不影响全网。
缺：距离有限；容易冲突；电缆一坏全断。
环型 Ring
首尾相连，数据沿一个方向绕圈。
优：电缆短、适合光纤、访问公平。
缺：一个节点坏可能全网断；加入/退出麻烦。
考点

“需要中心控制器或集线器（hub）的拓扑” → 星型。全连接网状网 n 个节点需要 n(n−1)/2 条链路，每个节点需要 n−1 个端口。

课件还讲了数据中心网络：传统三层架构（接入-汇聚-核心，用 STP 防环会阻塞一半链路）→ 云数据中心用 Leaf-Spine（叶脊）全互联架构 + Overlay（VXLAN）+ SDN 实现大规模、虚拟化、自动化。了解即可。

1.3 网络分类★★

没有统一的分类法，但两个维度最重要：传输技术和覆盖范围（距离尺度）。

按传输技术

  • 广播链路：大家共享一个信道，一个人发、所有人都收到（看地址判断是不是给自己的）。例：WiFi、早期以太网。
  • 点到点链路：一对机器之间连接；一个发送方对一个接收方，叫单播（unicasting）。

按规模

类型范围典型例子
PAN 个域网一个人身边蓝牙耳机、手环连手机
LAN 局域网一栋楼、一个校园交换式以太网（有线，802.3）、WiFi（无线，802.11）；公司里叫企业网
MAN 城域网一座城市基于有线电视网的城域网
WAN 广域网国家/大洲连接多个分公司的网络；ISP 网络；VPN（在因特网上用“虚拟链路”搭的广域网）
internet 互联网全球许多独立网络连在一起；最大的那个叫 the Internet
自测原题

“一栋楼/工厂/校园内的通信系统” → LAN；“跨州、跨国乃至全球” → WAN；“许多独立网络的集合” → an internet。

1.4 网络软件：分层、协议、接口、服务★★★

网络要做的事太多了（编码、纠错、找路、可靠传输……），全塞在一个程序里没法写。于是把它切成一层一层，每层只干一件事，并且只用下一层的服务、只给上一层提供服务。

必须分清的 6 个名词

名词一句话解释在比喻里
实体 / 对等实体 (peer)每层里干活的东西；不同机器上同一层的实体互称对等实体两个翻译互为对等实体
协议 Protocol对等实体之间通信的规则（水平方向）“两个翻译都用荷兰语”
服务 Service下层为上层提供的功能（垂直方向）；只说“能做什么”，不说“怎么做”翻译为哲学家提供“翻译”服务
接口 Interface相邻两层之间交换信息的连接点，规定下层向上层提供哪些原语操作哲学家把纸条递给翻译的那个窗口
网络体系结构层和协议的集合整个三层安排
协议栈某个系统所用的协议列表，每层一个斯瓦希里语/荷兰语/传真
考点 · 年年考
  • OSI 参考模型的三个主要概念：服务、接口、协议（2020、2022 填空）。
  • 第 N 层与第 N+1 层的关系：第 N 层为第 N+1 层提供服务（2021、2022 选择）。
  • 服务是垂直的（上下层之间），协议是水平的（对等层之间）。可以随便换协议，但不能随便改服务，因为服务对上层用户可见。

协议三要素（自测第 8–10 题）

语法 Syntax
数据的结构和格式，即各部分出现的顺序。（“说什么格式”）
语义 Semantics
每个比特模式是什么意思，收到后要做什么动作。（“是什么意思”）
时序 Timing
什么时候发、发多快。（“何时、多快”）

封装与解封装（本章难点）

发送时数据从上往下走，每经过一层就在前面加一个头部（链路层还会在尾部加尾部）。接收时从下往上走，每层剥掉自己那层的头。每层只看自己的头，不关心里面装的是什么。

考点 · 自测第 20 题

OSI 中数据包从低层往高层走时，头部被移除（removed）；从高层往低层走时，头部被添加（added）。

PDU、SDU、PCI 的关系（名词解释备用）

N 层 PDU = N 层 PCI（头部控制信息） + N 层 SDU（上层交下来的数据）
N 层 SDU = (N+1) 层 PDU
IDU（接口数据单元）= ICI（接口控制信息） + SDU PDU：对等实体之间交换的数据单元；SDU：上层交给本层“要帮我送”的数据；SAP（服务访问点）：层间接口上的“插座”，每个 SAP 有唯一地址。一个 SDU 太大时可能被切成多个 PDU。

分层的优点与缺点 ★★★

优点（作业第 2 题）
  • 各层相对独立：只需知道下层提供什么服务，不必知道怎么实现。
  • 灵活：某层协议改变，只要接口不变，就不影响其他层。
  • 结构上分开，每层可用最合适的技术。
  • 易于实现和维护（把大问题拆小）。
  • 促进标准化。
缺点
  • 有些功能会在多层重复实现（如差错检测），浪费资源、降低效率。
  • 层数不好定：太少每层太复杂，太多又难以描述和实现。
  • 每层都加头部，带来额外开销（见作业第 5 题）。

每一层都要考虑的设计问题：可靠性（检错纠错、绕开故障路由）、网络演进（编址、命名、分层）、资源分配（多路访问、拥塞控制）、安全（保密、认证）。

1.5 面向连接 vs 无连接★★★

面向连接 Connection-oriented无连接 Connectionless
比喻打电话：先拨通，再说话，最后挂断寄信：写好地址直接扔进邮筒
阶段三个阶段：建立连接 → 传数据 → 释放连接没有这些阶段，直接发
顺序保序：先发的先到每个包独立选路，可能走不同路径，到达顺序可能乱
代价建连要协商，确认（ACK）带来额外开销和时延开销小、快
例子TCP（可靠字节流）UDP；网络层的 IP（不可靠数据报）

“可靠”和“连接”是两个独立的维度。可靠 = 有确认、丢了会重传；不可靠 = 发完就不管了。组合起来有 6 种服务：

服务例子
面向连接可靠报文流按页发送的书稿（保留每页边界）
可靠字节流下载电影（TCP）
不可靠连接VoIP 网络电话（RTP）
无连接不可靠数据报垃圾邮件、IP
有确认的数据报挂号信
请求-应答数据库查询
报文流 vs 字节流（老作业 1-7）

进程先写 1024 字节，过一会儿又写 1024 字节，接收方一次读 2048 字节。报文流：收到两个 1024 字节的报文（保留边界）；字节流：收到一整块 2048 字节，原来“分两次发”的信息丢了。

考点
  • TCP 与 UDP 的主要区别（本学期作业第 6 题）：TCP 面向连接、可靠、保序、有流量控制，提供字节流；UDP 无连接、不可靠、不保序、开销小，适合实时音视频、DNS 查询。两者都跑在 IP 之上。
  • IP 是既不可靠也不面向连接的协议（自测第 24 题选 none of the above）。

  • 端到端应答、分组排序、流量控制 → 传输层（2023）；process-to-process 交付 → 传输层；node-to-node / 一站到下一站无差错 → 数据链路层；source-to-destination 跨多条链路 → 网络层。
  • 路由选择协议位于 网络层；网络层数据单位是 分组（2023）。
  • “数据链路层保证端到端数据正确传输”是错的，链路层只管相邻节点（2023）。
  • 通信子网 = 下三层（物理、链路、网络）；会话层不属于通信子网（2021）。
  • 把比特变成电磁信号 → 物理层；TCP/IP 的应用层 = OSI 的会话+表示+应用层（自测 30）。
  • OSI 由 ISO 提出，目的是让任何两个系统都能通信（自测 18、25）。
  • 常用端口（2021 选择）：HTTP 80、FTP 21、Telnet 23、SMTP 25、DNS 53、HTTPS 443。FTP 不是 31。

数据在路上：路由器只用到网络层

OSI 和 TCP/IP 的评价（简答可能考）

OSI：概念清晰，但没流行
  • 时机不好：出来时 TCP/IP 已经广泛使用。
  • 技术不好：会话层、表示层几乎没内容，七层不均匀，太复杂。
  • 实现不好：早期实现又慢又贵。
  • 政治不好：政府强推引起技术人员反感。
TCP/IP：协议成功，模型弱
  • 先有协议后有模型，模型是“事后总结”的。
  • 不通用：不适合描述非 TCP/IP 协议栈（如蓝牙）。
  • 没区分服务、接口、协议；没区分物理层和链路层。

1.8 性能：带宽、时延、抖动★★★

客户端-服务器系统的性能主要看两个指标：带宽（每秒能运多少比特）和时延（第一个比特从一端到另一端要多久）。

传输时延 = L / R　L 比特，R bps
传播时延 = d / v　真空/空气 v = 3×10⁸ m/s；铜线/光纤约 2×10⁸ m/s
时延带宽积 = R × 传播时延　线路上“装着”多少比特 课件例：100 Mbps、5000 km 光纤，时延 50 ms → 线路里同时有 10⁸×0.05 = 5×10⁶ 比特，1 km 装 1000 比特，即每个比特“长” 1 米。
高带宽≠低时延（老作业 1-1）

横跨大陆的光纤：带宽很高（Gbps），但光要跑几千公里，时延也高；卫星链路同理。同一栋楼里的 56 kbps 调制解调器：带宽低、时延也低。

“开一辆装满磁带的货车跑高速”带宽惊人（课件算出约 2 Tbps），但时延要好几天。

服务质量 QoS 还看什么（老作业 1-2）

语音、视频：需要均匀的交付时间，看抖动（jitter），即时延的波动；短时延但波动大，比时延稍长但稳定更糟。金融交易：看可靠性和安全性。自测：故障频率、故障后恢复时间衡量的是可靠性；未授权用户是安全问题。

简答 · 2023 第 5 题 / 本学期作业第 7 题

两种确认策略：A. 每个分组单独确认，整个文件不确认；B. 分组不确认，整个文件到达后确认一次。

  • 网络质量差（容易丢包） → 用 A：丢了哪个只重传哪个，比重传整个文件代价小。
  • 网络质量好 → 用 B：正常情况下只发一次确认，省带宽、处理简单；万一丢一个包就要重传整个文件，但这很少发生。

1. 5 台路由器点到点相连，每两台之间可以放高速、中速、低速线路或不放线。生成并检查一种拓扑要 100 ms，检查全部要多久？作业1

每个位置 4 种选择（高/中/低/无）→ 拓扑总数 4¹⁰ = 1,048,576。

总时间 1,048,576 × 0.1 s = 104,857.6 s ≈ 29.1 小时。

（老版题目是 50 ms，答案是约 14.6 小时；看清题目给的数字。）

2. 使用分层协议的两个理由？一个可能的缺点？作业2

理由：① 把设计问题拆成更小、更好处理的部分（易于实现和维护）；② 某层协议变化不影响其他层，只要接口不变（灵活、独立）。

缺点：性能可能变差（每层加头部开销、功能可能重复实现）；层数不好确定。

3. 无连接与面向连接通信的主要区别？各举一个协议作业3

面向连接有三个阶段：建立连接 → 传数据 → 释放连接，且保证顺序；无连接没有这些阶段，直接发数据，不保证顺序。

（1）无连接：UDP（或 IP）；（2）面向连接：TCP。

4. 链路层出错就要求重传。一帧受损概率为 p（确认不会丢），发送一帧平均需要传几次？作业4

每次传输成功的概率是 1−p。恰好传 k 次才成功的概率是 p^(k−1)·(1−p)（前 k−1 次都坏了）。

期望 E = Σ k·p^(k−1)·(1−p) = 1/(1−p)。

答：平均 1/(1−p) 次。直觉：成功率 1/2 时平均要 2 次。

5. n 层协议，应用报文长 M 字节，每层加 h 字节头部。头部占网络带宽的比例？作业5 · 课件 P6

头部总共 n·h 字节，整个报文 M + n·h 字节。

比例 = nh / (M + nh)。

没考虑分片（会增加开销）和聚合（会降低开销）。

6. TCP 和 UDP 的主要区别？作业6 · 课件 P4

TCP 面向连接，提供可靠的字节流（有确认、重传、保序、流量控制）；UDP 无连接，只是把数据报发出去，不保证到达和顺序，但开销小、时延低。

7. 文件传输的两种确认策略讨论作业7 · 2023 简答

见上面 1.8 的考点框：网络容易丢包时逐个确认；网络很可靠时整个文件确认一次（省带宽，但一旦丢包要重传整个文件）。

9. 第 k 层实现操作的算法变了，对第 k−1 层和 k+1 层有什么影响？作业9

没有影响。算法只是第 k 层内部的实现方式，它向上提供的服务、对下使用的服务都没变，接口不变，其他层感觉不到。这正是分层的好处。

10. 第 k 层提供的服务（操作集合）变了，对第 k−1 层和 k+1 层的服务有什么影响？作业10

第 k+1 层受影响：它是第 k 层服务的使用者，操作变了，k+1 层可能要修改（甚至它向上提供的服务也要变）。

第 k−1 层不受影响：它只为第 k 层提供服务，不关心第 k 层对上提供什么。

课件 P1：圣伯纳犬背 3 盘 7 GB 磁带，以 18 km/h 跑。距离多远以内，狗比 150 Mbps 的线路快？

狗运的数据：3 × 7 GB = 21 GB = 21 × 8 × 10⁹ = 1.68 × 10¹¹ 比特（按 1 GB = 10⁹ B）。

跑 x km 要 x / 18 小时 = 200x 秒，狗的速率 = 1.68×10¹¹ / (200x) bps。

令其 > 1.5×10⁸：x < 1.68×10¹¹ / (200 × 1.5×10⁸) = 5.6 km。

答：约 5.6 km 以内（若按 1 GB = 2³⁰ B 算约 6 km）。

课件 P2：卫星高 40,000 km，客户端-服务器请求的最好情况响应时延？

请求要上去再下来（2 × 40,000），响应也要上去再下来（2 × 40,000），共 160,000 km。

光速 300,000 km/s → 160,000 / 300,000 ≈ 0.533 s = 533 ms。

2.1 数据、信号与传输方式★★

数据是要运送的信息；信号是数据的电气或电磁表现形式。两者都可以是模拟的（连续变化，如指针表）或数字的（取值离散，如数字表从 8:05 直接跳到 8:06）。

正弦波的三要素（载波三要素）

考点 · 2020 填空

模拟信号传输的基础是载波，载波三要素：频率、振幅、相位。数字数据可以针对其中一个或组合进行调制（见 2.6）。

  • 周期信号：在一个周期内完成一个模式并不断重复（如正弦波）。非周期信号：没有重复模式（如说话的声音）。大多数数字信号是非周期的。
  • 时域图：横轴是时间，看信号怎么随时间变。频域图：横轴是频率，看信号由哪些频率组成。一个纯正弦波在频域里只是一根竖线。
  • 单一频率的正弦波没法携带信息（电力公司送 60 Hz 交流电、防盗报警可以用）。通信要用复合信号，即许多正弦波的叠加。

单工、半双工、全双工

并行 vs 串行；异步 vs 同步

  • 并行：多根线同时传多个比特（快，但线多、只适合短距离）。串行：一根线一个接一个传（网络里基本都是串行）。
  • 异步传输：以字符为单位，每个字符前加起始位（0）、后加停止位（1），字符之间可以有空闲。对时钟要求低。
  • 同步传输：以帧为单位，比特一个接一个，没有起止位和空隙，由接收方负责分组，时钟同步很重要。

2.2 带宽、波特率、比特率★★★

傅里叶：任何信号都是很多正弦波叠加

傅里叶分析说：任何周期信号都能拆成一个“基波”加上无数个“谐波”（频率是基波的整数倍）。数字方波边沿很陡，要无穷多个谐波才能拼出来，所以数字信号的带宽是无穷大。

可真实信道的带宽有限，高频谐波过不去，收到的波形就“变圆变形”。下面拖动滑块，看看信道只放过前 N 个谐波时，字符 “b”（01100010）变成什么样：

傅里叶演示：带宽越窄，波形越糊

灰色台阶 = 发出去的理想信号；彩色曲线 = 只保留前 N 个谐波后接收方看到的。N=1、2 时几乎认不出，N≥8 基本能判断出每一位。

信号带宽（Hz） = 最高频率 − 最低频率 例：一个复合信号的频率范围 1000–5000 Hz，带宽 = 4000 Hz。周期信号的频率是离散的（傅里叶级数），非周期信号的频率是连续的（傅里叶变换）。
易错 · “带宽”有两个意思

电子工程师说的带宽：信道能通过的频率范围，单位 Hz。

计算机人说的“带宽”：其实是信道容量 / 最大数据率，单位 bps。平时说“10 Mbps 带宽”就是这个意思。

公式里的 B 永远是 Hz。数据率是“用掉模拟带宽之后得到的结果”。比喻：带宽是路宽，信道容量是这条路的限速通行量。

波特率 vs 比特率（必考换算）

  • 码元（symbol）：一个信号脉冲/一个信号状态。
  • 波特率 RB（码元速率、符号率）：每秒传多少个码元，单位 Baud。
  • 比特率 Rb：每秒传多少比特，单位 bps。
  • 一个码元有 V 种状态，就能表示 log₂V 位。
Rb = RB × log₂V V=2（0/1 两个电平）：比特率 = 波特率；V=4（00/01/10/11）：比特率 = 2 × 波特率。
例题 · 真题三连
  • 2021：64-QAM 信号波特率 2000，比特率？ → 64 种状态，log₂64 = 6，2000 × 6 = 12000 bps。
  • 2023：波特率 600 Baud，4 种幅度 × 4 种相位 = 16 种码元，数据率？ → 600 × log₂16 = 600 × 4 = 2400 b/s。
  • 2020：8 种相位，每种相位 2 种幅度，一个码元表示几位？ → 8 × 2 = 16 种状态，log₂16 = 4 位。

2.3 信道的极限：奈奎斯特与香农★★★★

这是第 2 章每年必考的计算。记两个公式，再记一个规则。

奈奎斯特定理（1924）· 无噪声理想信道C = 2B log₂VB：带宽（Hz）；V：信号电平/状态数。
想更快：加带宽，或用更多电平。
香农定理（1948）· 有噪声信道C = B log₂(1 + S/N)S/N：信噪比（功率比，不是 dB！）。
香农上限与电平数无关，加多少电平也突破不了。
信噪比 dB = 10 × log₁₀(S/N)　⇔　S/N = 10^(dB/10) 10 dB → 10；20 dB → 100；30 dB → 1000；36 dB → 约 3981；40 dB → 10000。
分贝也用来比较两点功率

dB = 10 lg(P2/P1)：正数表示放大，负数表示衰减（光纤衰减就是这么算的），0 dB 表示两点功率相等 P2 = P1（第二章自测第 2 题）。

易错 · 最常见的丢分点

题目同时给了“二进制信号/几种电平”和“信噪比”时，要两个公式都算，取较小的那个。因为信道必须同时满足两个限制。

香农公式里一定先把 dB 换成比值，再代入。20 dB ≠ S/N = 20，而是 S/N = 100。

计算器：奈奎斯特 / 香农 / 取最小

例题（全部来自课件与真题）

例 1 · 2022 填空 / 老作业 2-2：3 kHz 信道，信噪比 20 dB，传二进制信号，最大速率？★必会

① 20 dB → S/N = 100。香农：3000 × log₂101 ≈ 3000 × 6.658 ≈ 19.97 kbps。

② 二进制 V=2。奈奎斯特：2 × 3000 × log₂2 = 6000 bps。

③ 取小：6 kbps。瓶颈是奈奎斯特。

例 2 · 2021 简答：4 kHz 带宽，信噪比 20 dB，传二进制信号，最大速率？

香农：4000 × log₂101 ≈ 26.63 kbps；奈奎斯特：2 × 4000 × 1 = 8 kbps。取小 → 8 kbps。

例 3 · 2023 填空 / 课件：PSTN 带宽 3000 Hz，4 种状态，无噪声最多多少位/秒？若信噪比 20 dB，理论最大速率？

无噪声用奈奎斯特：2 × 3000 × log₂4 = 12000 bps。

有噪声用香农：3000 × log₂(1+100) = 3000 × log₂101 ≈ 19,975 bps（课件写作 19 936 bps，近似误差，答 3000×log₂101 即可）。

例 4 · 课件：电话线带宽 3000 Hz，信噪比 3162，最大比特率？

C = 3000 × log₂(1 + 3162) = 3000 × log₂3163 ≈ 3000 × 11.63 ≈ 34.86 kbps。想更快只能加带宽或提高信噪比。

例 5 · 课件：SNRdB = 36，带宽 2 MHz，理论容量？

S/N = 10^3.6 ≈ 3981。C = 2×10⁶ × log₂3982 ≈ 2×10⁶ × 11.96 ≈ 24 Mbps。

例 6 · 课件：无噪声信道带宽 20 kHz，要传 265 kbps，需要多少电平？

265000 = 2 × 20000 × log₂V → log₂V = 6.625 → V ≈ 98.7。

不是 2 的整数次幂，所以要么增加到 128 级（速率 280 kbps），要么降低速率用 64 级（240 kbps）。

例 7 · 课件：信噪比几乎为 0 的极端噪声信道，容量是多少？

C = B log₂(1 + 0) = B × 0 = 0。无论带宽多大都收不到数据。

奈奎斯特的两个推论（课件）
  1. 带宽和编码方式定了，极限速率就定了，除非改善带宽。
  2. 提高比特率只有两条路：加带宽，或者用更多电平的编码（但香农给了天花板）。

2.5 基带传输：线路编码★★★

基带信号：从 0 Hz 到某个最高频率的信号，常用于有线（直接把电压加在线上）。通带信号：被“搬”到某个高频范围的信号，所有无线和光传输都是通带（见 2.6）。

线路编码就是“用什么电压波形代表 0 和 1”。好的编码要考虑三件事：

带宽效率
一个码元能带几位？电平越多，同样带宽传得越多。
时钟恢复（自同步）
接收方要知道每一位从哪开始、到哪结束。长串 0 或 1 没有跳变，接收方会数错位数。
直流分量 / 基线漂移
电压长时间不变，产生接近 0 Hz 的分量，有些系统过不去，接收端判决门限会漂。
动手画波形：输入比特，自动画出 6 种编码

约定按课件：NRZ 高=1；NRZI 遇 1 翻转；曼彻斯特 1=中间高→低，0=中间低→高；差分曼彻斯特每位中间必跳，位开始处有跳变表示 0、无跳变表示 1（初始电平设为高）；AMI 的 1 交替正负。考试若给了别的约定，以题目为准。

编码规则优点缺点
NRZ 不归零高电平=1，低电平=0；表示完一位电压不回零最简单，编码效率高没有自同步能力：长串 0/1 没跳变，收发双方会失步；有直流分量
RZ 归零正电平=1，负电平=0，每位后半段回到 0（三种电平）每位都有跳变，自同步（时钟藏在数据里）很大一部分带宽浪费在“归零”上
NRZI遇 1 翻转，遇 0 不变连续的 1 有跳变；USB 用它连续的 0 还是没跳变 → 配合 4B/5B 解决
曼彻斯特每位中间必有跳变：时钟与数据异或；课件规定 1 = 高→低，0 = 低→高自同步；经典以太网用它每位两个码元，需要 NRZ 的 2 倍带宽（效率 50%）
差分曼彻斯特中间必跳（只做时钟）；看位开始处：有跳变 = 0，无跳变 = 1自同步；只看“有没有跳变”，抗干扰更好同样带宽减半
AMI（双极）0 = 零电平；1 交替用正、负电平无直流分量；T1 线路用它长串 0 无跳变
伪三元和 AMI 相反：1 = 零电平，0 交替正负了解即可
4B/5B每 4 位查表换成 5 位，保证不出现超过 3 个连续 0，再用 NRZI 发送解决 NRZI 长串 0 问题，开销只有 25%编码效率 4/5 = 80%
2B1Q（多电平）2 位用 1 个四电平码元表示xByQ：x 位数据用 y 个码元；单个码元表达位数越多越高效

2.7 多路复用：FDM、TDM、WDM★★★

复用 = 多路信号共享一条信道（发送端复用器 MUX 合并，接收端分用器 DEMUX 拆开）。

FDM 频分多路复用

把信道带宽切成多个互不重叠的子频带，每路信号调制到不同载波频率上；相邻子信道之间留保护带（guard band）防止干扰。广播电台、有线电视就是 FDM。

例题 · 老作业 2-3

10 路信号各需 4000 Hz，用 FDM 复用，保护带 400 Hz，最小带宽？

10 路之间只需要 9 条保护带：4000 × 10 + 400 × 9 = 43,600 Hz。

OFDM 正交频分复用：子载波彼此“正交”，频谱可以部分重叠而不互相干扰（每个子载波的峰值正好落在别人的零点），比普通 FDM 更省频带。802.11 WiFi、4G、ADSL2 都用它。

WDM 波分复用：就是光纤上的 FDM，不同波长（颜色）的光在一根光纤里同时传。光纤通信用波分复用（2023 选择）。

TDM 时分多路复用

大家用同一个频率，按固定顺序轮流占用时间片。电话网、蜂窝网大量使用。

同步 TDM统计 TDM（异步 TDM）
时隙预先分好、固定不变；某用户没数据，他的时隙也空着 → 浪费按需动态分配时隙，谁有数据给谁；还能多给某用户几个时隙提高速率。（就是 1.1 的“统计复用”）

TDM vs TDMA：都把时间切成时隙。TDM 用于“复用”，时隙由发送方预先排好；TDMA（时分多址）用于“多址接入”，多个节点争用有限的时隙。课件比喻：商家自己排好供货顺序是 TDM；谁抢到谁供货是 TDMA。

自测高频
  • FDM 和 WDM 传的是模拟信号，TDM 传的是数字信号。
  • 链路带宽（Hz）比各路信号带宽之和还大时可以用 FDM；链路数据率比各路之和还大时可以用 TDM。
  • 分“同步”和“统计”两种的是 TDM。
简答 · 2022

列举四种多路复用并说明原理：时分（按时间片轮流）、频分（按不重叠的频带，加保护带）、波分（一根光纤里传多个波长）、码分（每个用户一个相互正交的码片序列，同时同频发送）。

2.8 码分多址 CDMA★★★★

CDMA 每年都考计算，且题型固定。步骤只有四步：

  1. 转双极：码片里的 0 → −1，1 → +1。例：00101110 → (−1 −1 +1 −1 +1 +1 +1 −1)。
  2. 发送：发比特 1 → 发自己的码片序列；发比特 0 → 发码片的反码（每位取负）；不发 → 全 0。
  3. 信道叠加：所有站同时发的序列按位相加，得到接收序列 S。
  4. 解码：想知道站 X 发了什么，算内积 S·X / m（对应位相乘再求和，除以码片长度 m）：结果 +1 → 发了 1，−1 → 发了 0，0 → 没发。
正交性：S·T = (1/m) Σ SᵢTᵢ = 0（不同站）　S·S = 1　S·S̄ = −1 因为不同站的码片两两正交，别人的信号在内积里全部抵消成 0，只剩下自己的。
CDMA 计算器（默认值 = 2021/2022 期中真题）

① 电话 Modem

② DSL / ADSL

③ FTTH 光纤到户

2.10 PCM、T1/E1 与 SONET★★★

干线是数字的，但人说话是模拟的。把模拟声音变成数字比特的最常用方法是 PCM 脉冲编码调制，它是模拟→数字转换（2020、2022 选择）。三步：

采样频率 ≥ 2 × 信号最高频率（奈奎斯特采样定理） 注意是“最高频率”，不是带宽！话音最高按 4000 Hz 算 → 每秒采样 8000 次 → 采样周期 1/8000 s = 125 μs。采样太慢会“混叠”（像视频里车轮看起来倒转）。
PCM 数据率 = 采样频率 × 每样本位数 每样本 8 位（256 级）：8000 × 8 = 64 kbps（一路电话）。每样本 7 位（128 级）：8000 × 7 = 56 kbps。
例题 · 2020/2021/2022 都考过

信道带宽 4000 Hz（2021 卷是 3400 Hz），采用 PCM，采样周期 125 μs，每样本量化为 128 个等级，数据率？

采样周期 125 μs → 每秒 8000 次；128 级 → log₂128 = 7 位；8000 × 7 = 56 kbps。答 56 kbps。带宽 3400 还是 4000 都不影响，因为采样周期已经给了。

k 跳路径的时延公式（2023 分析题 10 分 / 老作业 2-6）

2-1 波长 1 μm 处 0.1 μm 的光谱有多少带宽？

方法一（公式）：Δf = c·Δλ/λ² = 3×10⁸ × 0.1×10⁻⁶ / (10⁻⁶)² = 3×10¹³ Hz。

方法二（两端相减）：波长范围 0.95 ~ 1.05 μm，f = c/λ：3×10⁸/0.95×10⁻⁶ − 3×10⁸/1.05×10⁻⁶ ≈ 3.01×10¹³ Hz。

答：约 3×10¹³ Hz = 30 THz = 30 000 GHz。

2-2 3 kHz 信道、信噪比 20 dB、传二进制信号，最大速率？

20 dB → S/N = 100。香农 3000 × log₂101 ≈ 19 975 bps；奈奎斯特 2 × 3000 × log₂2 = 6000 bps。两个限制取小：6 kbps。

2-3 10 路各 4000 Hz 的信号 FDM，保护带 400 Hz，最小带宽？

10 路之间 9 条保护带：10 × 4000 + 9 × 400 = 43 600 Hz。

2-4 A、B、C 同时发 0（课本图 2-22(a) 码片），合成的码片序列？

课本码片：A (−1 −1 −1 +1 +1 −1 +1 +1)，B (−1 −1 +1 −1 +1 +1 +1 −1)，C (−1 +1 −1 +1 +1 +1 −1 −1)。发 0 = 发码片的反码，三者取反后相加：−A − B − C = (+3 +1 +1 −1 −3 −1 −1 +1)。

2-5 收到 (−1 +1 −3 +1 −1 −3 +1 +1)，用课本码片，哪些站发了什么？

课本 D = (−1 +1 −1 −1 −1 −1 +1 −1)。逐个做内积再除以 8：

S·A/8 = +1 → A 发 1；S·B/8 = −1 → B 发 0；S·C/8 = 0 → C 没发；S·D/8 = +1 → D 发 1。

可以用 2.8 的 CDMA 计算器验证（把码片换成课本的）。

2-6-1 比较 k 跳路径上电路交换与（轻负载）分组交换发 x 位报文的时延

电路交换：s + x/b + kd（建立电路 + 发送整条报文 + k 跳传播）。

分组交换：x/b + (k−1)p/b + kd（源端发完所有分组 + 最后一个分组在中间 k−1 个节点各存储转发一次 + 传播）。假设 x ≥ p，忽略头部、排队和处理时延。推导见 2.11 的流水线图。

2-6-2 什么条件下分组交换时延更小？

两式相减：s > (k−1)·p/b，即电路建立时间大于最后一个分组多出来的 k−1 次转发时间。

2-6-3 什么情况下分组交换比电路交换更合适？
  • 满足上面的时延条件时（建立电路很慢、分组小、跳数少）。
  • 突发性流量：大家统计复用链路，不用为空闲的电路占着带宽。
  • 需要容错：某个交换机或链路坏了，分组可以绕路走；电路交换的整条电路就断了。
2-7 每个分组 p 位数据 + h 位头部，x ≫ p+h，传播时延忽略，p 取多少总时延最小？

分组数约 x/p，总位数 (p+h)·x/p，源端发送用时 (p+h)x/(pb)；最后一个分组在中间路由器再转发 k−1 次，用时 (k−1)(p+h)/b。

T(p) = (p+h)/b · (x/p + k − 1)。对 p 求导：dT/dp = (1/b)·[(k−1) − xh/p²] = 0。

p = √( hx / (k−1) )（k > 1）。直觉：分组太大，流水线不起来；太小，头部开销太大。

2-8 5000 户，每根同轴电缆下行 100 Mbps，保证每户至少 2 Mbps，怎么办？

一根电缆最多带 100/2 = 50 户，5000 户要 5000/50 = 100 根同轴电缆段，每段直接接到一个光纤节点（光纤这一侧也要有足够容量）。

2-9 两个 VSAT 经 hub 传 1 GB 文件，上行 1 Mbps、下行 7 Mbps，电路交换，建立 1.2 s，要多久？

瓶颈是 1 Mbps 的上行。按课件约定 1 GB = 1024 × 8 Mb，发送用时 8192 s。

经 hub 要“上-下-上-下”四段：4 × 35 800 / 300 000 ≈ 0.48 s。

总计 1.2 + 8192 + 0.48 = 8193.68 s（约 2 小时 17 分）。

单位口径不同结果会差几百秒：若 1 GB = 10⁹ 字节、1 Mbps = 10⁶ bps，约 8001.68 s；若 1 GB = 2³⁰ 字节、Mbps 按十进制，约 8591.6 s。考试写清楚你的假设即可。

2-10 同上改用分组交换：分组 64 KB，卫星和 hub 交换时延 10 μs，头部 32 字节

1 GB / 64 KB = 16 384 个分组（老版答案写的“16”应理解为 16K），头部共 16 384 × 32 B = 512 KB，总共 1024.5 MB。

按课件口径：发送 1024.5 × 8 = 8196 s，加传播 0.48 s 和 3 次交换 3 × 10 μs，约 8196.48 s。比电路交换还慢一点：省掉了 1.2 s 建立时间，却多传了 512 KB 头部（4 s）。

更严格的存储转发流水线算法（四段链路 1、7、1、7 Mbps，十进制速率，1 GiB 文件）约 8595 s。结论一样：链路这么慢时，分组交换的头部开销反而让它更慢。

3.1 链路层干什么；三种服务★★★

物理层只会送“一串比特”，不管它们是什么意思、错没错。数据链路层要做到：相邻两个节点之间（一条链路、一跳）可靠、高效地传数据。它做四件事：

① 成帧
把网络层的分组装进帧（帧头 + 数据 + 帧尾），让接收方知道一帧从哪开始、到哪结束。
② 差错控制
发现（甚至纠正）传输中翻转的比特；出错就重传。
③ 流量控制
别让快的发送方把慢的接收方“淹没”。
④ 向网络层提供服务
一个定义良好的接口。
  • 链路 = 两个相邻节点之间的物理通路（中间没有交换节点）；数据链路 = 链路 + 控制传输的协议。
  • 点到点链路独占介质（如 PPP、HDLC）；广播链路多对设备共享介质（如以太网、WiFi），要先解决“谁能发”的问题，那是第 4 章的 MAC 子层。
  • 链路层分两个子层：逻辑链路控制 LLC（也叫数据链路控制 DLC，处理点到点和广播都有的问题）和介质访问控制 MAC（只处理广播链路的争用问题）。2023 填空就考这两个名字。
链路层能提供的服务特点例子
无确认的无连接服务直接发，不确认、不重传，丢了靠上层处理以太网（误码率低）
有确认的无连接服务每帧都要确认，没确认就重传802.11 无线局域网（误码率高，确认有必要）
有确认的面向连接服务先建立连接、帧编号、保证每帧恰好收到一次且按顺序很少见（如长距离不可靠链路）
考点 · 2023 简答原题

“请给出数据链路层可能提供的服务类型及对应的网络实例” → 直接答上表三行。注意没有“无确认的面向连接服务”这一种。

3.2 成帧：字节计数、字节填充、位填充★★★★

接收方收到的是连续的比特流，怎么知道一帧在哪里结束？课件给了四种方法：

字节填充的规则

  1. 帧首尾各放一个标志字节 FLAG。
  2. 数据里如果出现 FLAG，在它前面插一个转义字节 ESC。
  3. 数据里如果出现 ESC 本身，也在它前面再插一个 ESC。
  4. 接收方看到 ESC 就把它删掉，把后面那个字节当普通数据。

ESC 是 ASCII 里的一个控制字符（一个字节），不是 “E”“S”“C” 三个字母。

位填充的规则

  1. 帧首尾的标志是 01111110（6 个 1）。
  2. 发送方在数据里每数到连续 5 个 1，就在后面插一个 0（不管下一位本来是什么）。
  3. 接收方每数到连续 5 个 1，就把后面紧跟的 0 删掉。这样数据里永远不会出现 6 个连续的 1，不会被误认为标志。
填充计算器（插入的部分标红）

字节填充时用空格分隔，如 A B ESC C ESC FLAG FLAG D。

考点 · 四年都考
  • 作业 3-1 / 2022 填空：A B ESC C ESC FLAG FLAG D → A B ESC ESC C ESC ESC ESC FLAG ESC FLAG D。
  • 2020 填空：01111110111110 位填充 → 0111110101111100。
  • 2021 选择：0111110111111110 → 011111001111101110（A）。
  • 2023 填空：010111110 → 0101111100。注意：最后虽然是数据结尾，凑满 5 个 1 也要补 0。

3.3 差错控制与流量控制★★

单比特错误
一个数据单元里只有 1 位翻转（0↔1）。
突发错误 burst
2 位或更多位翻转（自测第 2 题）。突发长度从第一个错位算到最后一个错位，中间的位不一定都错。

纠错比检错难：检错只要回答“有没有错”；纠错还得知道错了几位、错在哪。

前向纠错 FEC（开环）检错 + 重传 ARQ（反馈）
做法多加冗余，接收方自己把错纠正只检错，出错就让发送方重发
代表海明码、卷积码、RS 码、LDPC奇偶校验、校验和、CRC + 停等 / 滑动窗口
适合重传代价大的情况（见作业 3-2）误码率低、往返时延小的链路
  • 差错控制的三件套：接收方发确认（ACK 肯定 / NAK 否定）；发送方设定时器，防止帧或确认丢了以后永远等下去；给帧编序号，接收方才能分辨“这是重传的旧帧还是新帧”。
  • 流量控制两种：基于反馈（接收方告诉发送方“还能发多少”，链路层和传输层都用）；基于速率（协议内置速率上限，不用反馈，只在传输层见到）。

3.4 海明距离★★★

一个 (n, m) 码：m 位数据 + r 位校验 = n 位码字。

  • 两个码字的海明距离 = 对应位不同的个数（两者异或后数 1 的个数）。例：10001001 与 10110001 异或 = 00111000，距离 3。
  • 一套编码的海明距离 = 所有合法码字两两之间距离的最小值。例：{0000000000, 0000011111, 1111100000, 1111111111} 的距离是 5。
  • 相同码字之间的距离是 0（自测第 7 题）。
检测 d 位错误：需要海明距离 ≥ d + 1
纠正 d 位错误：需要海明距离 ≥ 2d + 1 直觉：从一个合法码字出发走 d 步（错 d 位）到不了另一个合法码字，就能发现；如果离原码字比离任何别的码字都近，就能“就近”改回去。例：距离 5 的码能检测 4 位错、纠正 2 位错。课件例 {00000, 01011, 10101, 11110} 距离 3：检 2 纠 1。
考点
  • 2022 填空：海明距离为 d+1 的编码能检测出 d 个比特错误；要纠正 d 个比特错误，需要海明距离为 2d+1 的编码。
  • 自测第 5 题：保证纠正 5 位错，最小海明距离至少 2×5+1 = 11。
  • 2021、2022 名词解释考过“海明距离”：两个码字对应位不同的位数；一种编码的海明距离是任意两个合法码字间距离的最小值，它决定了检错和纠错能力。

3.5 奇偶校验与海明码★★★★

奇偶校验

加一个校验位，让 1 的个数变成偶数（偶校验）或奇数（奇校验）。例：1110000 偶校验 → 11100001。

  • 只能发现奇数个位出错（错 1 位、3 位能查出，错 2 位查不出）——自测第 6 题。对随机长突发错误，只有一半概率查出。
  • 二维奇偶 / 交织：把数据排成 k 行 n 列，每列算一个校验位，按行发送。n 个校验位能查出长度 ≤ n 的突发错误。

3.6 校验和 Checksum★★★

把数据切成若干个 N 位的“字”，全部相加，结果取反作为校验和。因特网用 16 位，作业里用 4 位练手。

  1. 反码求和（one's complement sum）：普通相加，最高位溢出的进位要加回最低位（循环进位）。
  2. 校验和 = 和的反码（每位取反）。
  3. 接收方把所有字连同校验和一起反码求和，结果应为全 1，取反为全 0 → 无错。
校验和计算器
例题 · 作业 3-5

消息 1001 1100 1010 0011，4 位字：1001 + 1100 = 1 0101 → 进位加回：0101 + 1 = 0110；0110 + 1010 = 1 0000 → 0000 + 1 = 0001；0001 + 0011 = 0100。校验和 = 0100 取反 = 1011。

  • 4 位反码：+7 = 0111，−7 = 1000（每位取反，自测第 9 题）。
  • 1111 和 1111 的校验和：1111 + 1111 = 1 1110 → 1110 + 1 = 1111，取反 = 0000（自测第 10 题）。
  • 检错方法里用反码运算的是校验和（自测第 1 题）。
  • 缺点：对字的顺序不敏感，两个字对调就查不出来 → 改进算法 Fletcher、Adler 校验和。

3.7 循环冗余校验 CRC★★★★★

比特串看成多项式的系数：1000011 ↔ x6 + x + 1。发送方和接收方事先约定一个生成多项式 G(x)（最高位和最低位都是 1）。

设 G(x) 是 r 次（对应 r+1 位），CRC 校验码就是 r 位：
① 数据后面补 r 个 0
② 用 G(x) 做模 2 除法（每一步都是“异或”，不借位不进位）
③ 余数（不足 r 位前面补 0）就是 CRC，接在原数据后面发出去
④ 接收方用整串除以 G(x)，余数为 0 → 没错；不为 0 → 出错 模 2 运算里加法和减法都是异或（XOR），自测第 3 题。
CRC 计算器（带竖式过程）
例题 · 2022 期中

数据 1010001101，G(x) = x5+x4+x2+1（110101），r = 5。补 5 个 0 后做模 2 除法，余数 01110，发送 101000110101110。用上面的计算器能看到每一步。

CRC 的检错能力条件
所有单比特错误G(x) 不止一项，且含 x0 项（最低位是 1）
所有奇数个位的错误G(x) 含因子 x + 1
所有长度 ≤ r 的突发错误r 位校验
长度 = r+1 的突发：概率 1 − (1/2)r−1；长度 > r+1：概率 1 − (1/2)r
查不出来的错误多项式 E(x) 恰好能被 G(x) 整除

常用标准：CRC-12 = x12+x11+x3+x2+x+1，CRC-16 = x16+x15+x2+1，CRC-CCITT = x16+x12+x5+1，以太网用 32 位 CRC。CRC 比校验和强，可以用移位寄存器 + 异或电路高速实现。

考点
  • 2020、2021、2022 选择 + 自测第 8 题：生成多项式含 x + 1 因子时，可检测所有奇数位错误。
  • 作业 3-4：x7+x5+1 除以 x3+1 的余数 → 10100001 ÷ 1001，余数 111，即 x2+x+1。（这里是直接相除，不补 0。）
  • 2021 期中：消息 11100011，G = x3+1 → 余数 100，发送 11100011100；最左位翻转后收到 01100011100，余数 010 ≠ 0 → 发现错误。
  • 2023 期中：帧 1010，G = x2+x+1 → CRC = 10，最终编码 101010。
  • 名词解释“循环冗余校验码”：把信息看作多项式 M(x)，补 r 个 0 后用约定的生成多项式 G(x) 做模 2 除法，余数作为校验位附在后面发送；接收方相除余数为 0 则认为无错。能检测所有奇数位错（G 含 x+1）、所有双比特错和所有长度 ≤ r 的突发错。

3.8 基本协议：从乌托邦到停等 ARQ★★★★

协议假设加了什么
p1 乌托邦单工信道不出错，接收方无限快什么控制都没有，发送方一直发
p2 无差错信道停等信道不出错，但接收方可能慢流量控制：发一帧，等接收方回一个“哑帧”（确认）再发下一帧。这个确认只表示“可以发下一帧了”
p3 有噪声信道停等（ARQ / PAR）帧和确认都可能出错或丢失差错控制：校验码 + 确认 + 定时器 + 1 位序号（0/1 交替）

ARQ = Automatic Repeat reQuest，自动重传请求（自测第 11 题）；也叫 PAR（带重传的肯定确认）。802.11 就是停等 + 重传，序号 12 位。

考点
  • 2022 选择：停等协议中数据帧丢失，发送方会永远等下去，解决办法是 → 超时重传（D）。
  • 2023 简答（6 分）：没有序号会怎样？→ 上图 ③。发送方成功发送一帧，接收方的 ACK 丢失，发送方超时重传，接收方无法分辨重传帧和新帧，会把它当新帧重复交给上层。有了序号，接收方能丢弃重复帧，并通过确认号告诉发送方期待的帧。
  • 老版作业：没有任何帧丢失，也可能收到重复帧吗？→ 可能：确认到得太晚（接收方 CPU 忙），发送方的定时器先到期重发了。

停等协议的信道利用率

tf = L / b（发一帧的时间），tp = 单程传播时延
U = tf / (tf + 2tp)　（确认帧很短、处理时间忽略）
确认要捎带在一个数据帧上时：U = tf / (2tf + 2tp) U ≥ 50% ⇔ tf ≥ 2tp ⇔ L ≥ 2·b·tp：发一帧的时间至少等于往返传播时延。
例题三连
  • 作业 3-6：4 kbps，传播时延 20 ms，利用率 ≥ 50% → L ≥ 2 × 4000 × 0.02 = 160 位。帧长 ≥ 160 bit 即可。
  • 2020 / 2022 期中：20 kb/s，传播时延 30 ms → L ≥ 2 × 20000 × 0.03 = 1200 位。（原卷的数字在公式图片里：lf ≥ C × 2tp = 20000 × 0.06 = 1200。）
  • 2023 选择：卫星传播时延 270 ms，64 kb/s，帧长 4000 bit，停等最大利用率 → tf = 62.5 ms，U = 62.5 / (62.5 + 540) ≈ 0.104（A）。

3.9 滑动窗口：回退 N（协议 5）与选择重传（协议 6）★★★★★

停等一次只有一帧在路上，长链路上大部分时间在干等。滑动窗口让发送方在收到确认前连续发多帧（流水线）。

  • 发送窗口：已发出但还没被确认、以及允许马上发的帧序号范围。收到确认，窗口下沿向前滑。发送方要把窗口内的帧都缓存着，以备重传。
  • 接收窗口：接收方愿意接收的序号范围，按序收到后向前滑。
  • 捎带确认（piggybacking）：收到数据帧后先不单独回 ACK，等自己有数据要发时，把确认号顺便放进数据帧的头部。省带宽；但等太久会让对方超时重传（名词解释 2021）。
  • 累积确认：ACK n 表示 n 以及 n 之前的帧都收到了。ACK 2 丢了，ACK 3 也能顶上。
  • NAK（否定确认）：接收方发现缺帧时立即要求重传那一帧，不用等超时。
n 位序号（0 ~ 2n−1）发送窗口最大接收窗口出错时重传接收方
停等（1 位滑动窗口，协议 4）11那一帧最简单
回退 N（GBN，协议 5）2n − 11出错帧及其后面所有已发的帧只按序接收，乱序的直接丢弃，只缓存 1 帧
选择重传（SR，协议 6）2n−12n−1只重传出错/丢失的那一帧窗口内乱序帧先缓存，配合 NAK；每帧一个定时器

为什么窗口不能再大

回退 N：W ≤ 2n − 1
3 位序号（0~7）时若窗口取 8：发送 0~7，收到对 7 的确认，再发新的 0~7，又收到对 7 的确认。发送方分不清是“第二批全到了”还是“第二批全丢了、对方在重复确认上一批”。所以最多同时有 MAX_SEQ = 7 帧未确认。
选择重传：W ≤ 2n−1，即 NR_BUFS = (MAX_SEQ+1)/2
接收窗口向前滑之后，新窗口和老窗口的序号不能重叠。否则所有确认丢失时，发送方重传的旧帧会落进新窗口，被当成新帧收下，接收方区分不出来（见下图）。
简答 · 2020、2022 原题

为何选择重传协议中要设置 #define NR_BUFS ((MAX_SEQ + 1)/2)？→ 把窗口最大尺寸限制为序号空间的一半，确保接收方向前移动窗口后，新窗口与老窗口的序号没有重叠。否则当所有确认都丢失时，后续到来的帧可能是重复的旧帧，也可能是新帧，接收方无法区分，会把错误的分组交给网络层。

利用率与需要的窗口

一个周期 T = tf + 2tp（确认要占一帧时间时再 + tf）
一个周期内最多能发 a = T / tf 帧
U = min(1, W·tf / T) = min(1, W / a)
要让管道一直满：W ≥ a，即课件的 W ≥ 2BD + 1（BD = 带宽 × 单程时延 / 帧长，以帧为单位） 然后由 W 反推序号位数：回退 N 要 2n − 1 ≥ W；选择重传要 2n−1 ≥ W。课件例：50 kbps，单程 250 ms，1000 位帧 → BD = 12.5 → W = 26。

波特率每秒传送的码元数，单位 Baud；比特率 = 波特率 × log₂V。
多路复用多路信号共享同一传输介质的技术，提高线路利用率；有频分、时分、波分、码分。
统计时分复用按需动态分配时隙，只有用户有数据时才分配，避免同步 TDM 中的空闲时隙浪费。
PCM脉冲编码调制，把模拟信号数字化的方法：按不低于最高频率两倍的速率采样，再量化、编码为二进制。
曼彻斯特编码每个比特中间都有一次电平跳变，跳变方向表示 0 或 1，具有自同步能力，但所需带宽是 NRZ 的两倍；经典以太网使用。
电路交换通信前在两端之间建立一条专用物理通路，通信期间独占，结束后拆除；时延稳定但可能浪费带宽，如电话网。
分组交换把数据分成有限长度的分组，各分组独立地存储-转发，无需建立连接，线路利用率高但时延不固定，如因特网。
时延带宽积传播时延 × 数据率，表示链路上同时能容纳的比特数。

名词解释：循环冗余校验码 / 海明距离 / Piggybacking / ARQ / Sliding Window2020–2022

CRC：把要传的信息看作多项式，补 r 个 0 后用约定的生成多项式做模 2 除法，余数作为校验位附在后面；接收方相除余数为 0 则无错。可检测所有奇数位错（生成式含 x+1）、双比特错和长度 ≤ r 的突发错。

海明距离：两个码字对应位不同的位数；一种编码的海明距离是任意两个合法码字之间距离的最小值，检测 d 位错需要 d+1，纠正 d 位错需要 2d+1。

Piggybacking 捎带确认：接收方收到数据帧后暂不单独发确认，而是把确认号附在自己下一个发出的数据帧里，节省带宽；等待不能超过对方的超时时间。

ARQ 自动重传请求：接收方检错并回送确认，发送方设定时器，超时或收到否定确认就重传；帧要编序号以识别重复帧。停等、回退 N、选择重传都是 ARQ。

Sliding Window 滑动窗口：发送方在收到确认前可以连续发送窗口内的多个帧，收到确认后窗口向前滑动；接收方按接收窗口接收。提高长时延链路的利用率，同时实现流量控制。
