# 第三章作业（中文翻译与答案）

## 一、简答题（共10题，100分）

1. **3-1.** 以下数据片段出现在使用教材中所述字节填充算法的数据流中间：`A B ESC C ESC FLAG FLAG D`。经过字节填充后的输出是什么？

2. **3-2.** 你能想到在什么情况下，开环协议（例如汉明码）可能比本章讨论的反馈型协议更可取吗？

3. **3-3.** 一个二进制值为 `10101111` 的 8 比特字节要使用偶校验汉明码进行编码。编码后的二进制值是什么？

4. **3-4.** 将 $x^7 + x^5 + 1$ 除以生成多项式 $x^3 + 1$ 得到的余数是什么？

5. **3-5.** 假设使用因特网校验和（4 比特字）传输报文 `1001 1100 1010 0011`。校验和的值是多少？

6. **3-6.** 一条信道的比特率为 4 kbps，传播延迟为 20 ms。帧大小在什么范围内时，停等协议（stop-and-wait）的效率至少能达到 50%？

7. **3-7.** 一条 3000 km 长的 T1 中继线用于使用协议 5（Protocol 5）传输 64 字节的帧。如果传播速度为 $6\text{ μs/km}$，序号（sequence numbers）应该有多少位？

8. **3-8.** 在协议 6（Protocol 6）中，当一个数据帧到达时，会检查其序号是否与期望的序号不同且 `no_nak` 为真。如果两个条件都成立，则发送一个 NAK；否则，启动辅助定时器（auxiliary timer）。假设省略了这个 `else` 子句，这一改动会影响协议的正确性吗？

9. **3-9.** 假设从协议 6（Protocol 6）代码末尾附近删除那段包含三条语句的 `while` 循环。这会影响协议的正确性，还是仅仅影响性能？请解释你的回答。

10. **3-10.** 长度为 1000 比特的帧通过 1 Mbps 的信道，经由地球同步卫星发送（卫星到地球的单程传播时间为 270 ms）。确认信息总是捎带在数据帧上。首部非常短。使用 3 比特序号。对于以下协议，所能达到的最大信道利用率分别是多少？
    - (a) 停等协议（Stop-and-wait）
    - (b) 协议 5（Protocol 5）
    - (c) 协议 6（Protocol 6）

## 二、参考答案与解析

1. **答案：** `A B ESC ESC C ESC ESC ESC FLAG ESC FLAG D`
   - **解析：** 在字节填充算法中，数据流中出现的每一个 `ESC` 或 `FLAG` 字节前面都要插入一个额外的 `ESC` 进行转义。

2. **答案：** 在以下情况下开环协议（前向纠错，如汉明码）比反馈型协议（ARQ）更可取：
   - **单向信道：** 没有反向信道可供接收方发回确认或重传请求（如某些广播或单向遥测链路）。
   - **传播延迟极高：** 例如深空通信或长距离卫星链路，等待反馈重传的往返延迟代价过大。
   - **严格实时性要求：** 如实时音视频流媒体，不能容忍重传带来的额外延迟与抖动。
   - **一对多组播/广播：** 大量接收方同时发回确认/否认会导致“反馈内爆”（feedback implosion）。

3. **答案：** `101001001111`
   - **解析：** 8 位数据需要 4 位校验位（位置 1、2、4、8），共 12 位码字（位置 1～12）。数据位依次填入位置 3、5、6、7、9、10、11、12：
     $d_3=1,\ d_5=0,\ d_6=1,\ d_7=0,\ d_9=1,\ d_{10}=1,\ d_{11}=1,\ d_{12}=1$。
     按偶校验计算校验位：
     - $p_1$（覆盖 1, 3, 5, 7, 9, 11）：数据位之和为 $1+0+0+1+1=3$（奇数）$\implies p_1=1$
     - $p_2$（覆盖 2, 3, 6, 7, 10, 11）：数据位之和为 $1+1+0+1+1=4$（偶数）$\implies p_2=0$
     - $p_4$（覆盖 4, 5, 6, 7, 12）：数据位之和为 $0+1+0+1=2$（偶数）$\implies p_4=0$
     - $p_8$（覆盖 8, 9, 10, 11, 12）：数据位之和为 $1+1+1+1=4$（偶数）$\implies p_8=0$
     故编码结果为 `101001001111`。

4. **答案：** $x^2 + x + 1$（二进制表示为 `111`）。
   - **解析：** 在模 2 算术下：
     $$(x^7 + x^5 + 1) \div (x^3 + 1)$$
     - 商为 $x^4 + x^2 + x$
     - $(x^7 + x^5 + 1) - (x^4 + x^2 + x)(x^3 + 1) = x^2 + x + 1$。

5. **答案：** `1011`
   - **解析：** 使用 4 比特反码加法（进位回卷）：
     - `1001 + 1100 = 10101` $\to$ 回卷：`0101 + 1 = 0110`
     - `0110 + 1010 = 10000` $\to$ 回卷：`0000 + 1 = 0001`
     - `0001 + 0011 = 0100`
     对结果 `0100` 按位取反，得到校验和 **`1011`**。

6. **答案：** 帧大小至少为 **160 比特**（即 **20 字节**）。
   - **解析：** 设帧传输时间为 $T_f$，单程传播延迟 $T_p = 20\text{ ms}$，往返传播延迟 $2T_p = 40\text{ ms}$（忽略确认帧传输时间与处理延迟）。效率满足：
     $$\eta = \frac{T_f}{T_f + 2T_p} \ge 0.5 \implies T_f \ge 2T_p = 40\text{ ms}$$
     因此最小帧长为 $L = 4000\text{ bps} \times 0.04\text{ s} = 160\text{ bits}$。

7. **答案：** **7 比特**。
   - **解析：** T1 线路速率为 $1.544\text{ Mbps}$，帧长为 $64 \times 8 = 512\text{ bits}$。
     - 单程传播延迟：$T_p = 3000 \times 6\text{ μs} = 18\text{ ms}$
     - 帧发送时间：$T_f = 512 / 1,544,000 \approx 0.3316\text{ ms}$
     - 为使信道保持满载，发送窗口需满足 $W \ge 1 + \dfrac{2T_p}{T_f} = 1 + \dfrac{36}{0.3316} \approx 109.56$，即 $W \ge 110$。
     在协议 5（回退 N 帧）中，最大发送窗口为 $2^n - 1$。因为 $2^6 - 1 = 63 < 110$，而 $2^7 - 1 = 127 \ge 110$，所以序号至少需要 **7 比特**。

8. **答案：** **会影响协议的正确性**（具体表现为在单向数据流场景下无法推进窗口）。
   - **解析：** 在协议 6 中，如果对方没有反向数据帧可发送以捎带确认（ACK），接收方必须依赖辅助定时器超时后发送独立的 ACK 帧。若省略该 `else` 子句，辅助定时器永远不会被启动，独立 ACK 永远不会发出；即使发送方超时重传同一帧，由于接收方已更新 `frame_expected`，重复帧也不会触发 `if` 分支，依然不会发 ACK。最终发送方窗口被填满且无法收到确认，协议陷入死锁/活锁。

9. **答案：** **会影响协议的正确性**（不仅仅是性能）。
   - **解析：** 协议 6 末尾的三条语句 `while` 循环用于处理收到的捎带确认（推进 `ack_expected`、减少已缓冲帧计数 `nbuffered` 并释放发送缓冲区）。如果删除该循环，发送方将永远无法确认已发送的帧、无法释放缓冲区，发送窗口很快就会填满并永久停止接收来自网络层的新分组，导致协议死锁。

10. **答案：**
    每帧发送时间 $T_f = 1000 / 10^6 = 1\text{ ms}$，双程传播延迟 $2T_p = 2 \times 270 = 540\text{ ms}$。由于确认捎带在反向数据帧（同样 1 ms）上，一个完整往返周期为 $1 + 540 = 541\text{ ms}$（若计入反向帧发送时间则为 $542\text{ ms}$，两者数值几乎一致）：
    - **(a) 停等协议：** 窗口大小 $W = 1$，最大利用率 $= \dfrac{1}{541} \approx \mathbf{0.185\%}$（若分母取 542 亦约为 $0.185\%$）。
    - **(b) 协议 5（回退 N 帧）：** 3 比特序号的最大发送窗口 $W = 2^3 - 1 = 7$，最大利用率 $= \dfrac{7}{541} \approx \mathbf{1.29\%}$。
    - **(c) 协议 6（选择重传）：** 3 比特序号的最大发送窗口 $W = 2^{3-1} = 4$，最大利用率 $= \dfrac{4}{541} \approx \mathbf{0.74\%}$。
