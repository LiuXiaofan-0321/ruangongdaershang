6. **2-6-1** 比较在电路交换网络和（轻负载的）分组交换网络中，通过 $k$ 跳路径发送 $x$ 比特报文的延迟。电路建立时间为 $s$ 秒，每跳传播延迟为 $d$ 秒，分组大小为 $p$ 比特，数据速率为 $b$ bps。在什么条件下分组交换网络具有更低的延迟？并说明在什么条件下分组交换网络比电路交换网络更可取。

## 二、参考答案与解析

1. **答案：** 约为 **$3.0 \times 10^{13}\text{ Hz}$**（或 **30,000 GHz**）。
   - **解析：** 波长范围为 $0.95\text{ μm}$ 到 $1.05\text{ μm}$。由 $f = c / \lambda$，带宽为：
     $$\Delta f = \frac{3\times 10^8}{0.95\times 10^{-6}} - \frac{3\times 10^8}{1.05\times 10^{-6}} \approx 3.01\times 10^{13}\text{ Hz}$$

2. **答案：** **6 kbps**。
   - **解析：** 20 dB 信噪比意味着 $S/N = 10^{20/10} = 100$。香农极限为 $3000 \log_2(1 + 100) \approx 19,975\text{ bps}$。对于二进制信号，奈奎斯特极限为 $2B \log_2(2) = 2 \times 3000 = 6000\text{ bps}$。取两者中的较小值，因此最大可达数据速率为 6 kbps。

3. **答案：** **43,600 Hz**（即 **43.6 kHz**）。
   - **解析：** 10 个信号之间需要 9 个保护带。最小带宽为 $10 \times 4000 + 9 \times 400 = 43,600\text{ Hz} = 43.6\text{ kHz}$。

4. **答案：** `(+3, +1, +1, -1, -3, -1, -1, +1)`。
   - **解析：** 发送比特 0 表示发送站点码片序列的相反数，因此合成序列为 $-A - B - C = (+3, +1, +1, -1, -3, -1, -1, +1)$。

5. **答案：** **A 和 D 发送了 1，B 发送了 0，C 未发送（静默）**。
   - **解析：** 令 $S = (-1, +1, -3, +1, -1, -3, +1, +1)$。计算归一化内积得：$S\cdot A/8 = +1$，$S\cdot B/8 = -1$，$S\cdot C/8 = 0$，$S\cdot D/8 = +1$。因此 A、D 发送了 1，B 发送了 0，C 保持静默。

6. **答案：**
   - 电路交换总延迟：$T_{\text{circuit}} = s + \dfrac{x}{b} + kd$。
   - 存储转发分组交换总延迟（假设 $x \ge p$ 且首部、排队与处理延迟可忽略）：$T_{\text{packet}} = \dfrac{x}{b} + \dfrac{(k-1)p}{b} + kd$。
   - 当 $s > \dfrac{(k-1)p}{b}$ 时，分组交换网络延迟更低。
   - 分组交换更适用于**突发性流量**（可共享链路容量）、**电路建立延迟较大**的场景，以及需要通过备用路由实现**容错（抗单点链路/交换机故障）**的场景。

7. **答案：** 当 $s > \dfrac{(k-1)p}{b}$ 时，分组交换网络具有更低的延迟（假设分组首部、排队及处理延迟可忽略）。

8. **答案：** 当网络中存在**突发性流量**时，分组交换更可取，因为用户可以在空闲时不占用专线而共享链路容量；此外，当电路建立会引入较大延迟，或需要在交换机/链路故障时通过备用路由重新转发分组以提供容错能力时，分组交换也更具优势。

9. **答案：** $p = \sqrt{\dfrac{xh}{k-1}}$ 比特（$k > 1$）。
   - **解析：** 约需要 $x/p$ 个分组，总延迟为 $T(p) = \dfrac{p+h}{b}\left(\dfrac{x}{p} + k - 1\right)$。对 $p$ 求导得 $\dfrac{\mathrm{d}T}{\mathrm{d}p} = \dfrac{1}{b}\left(-\dfrac{xh}{p^2} + k - 1\right)$，令导数为 0 解得 $p^2 = \dfrac{xh}{k-1}$，即 $p = \sqrt{\dfrac{xh}{k-1}}$（采用连续近似）。

10. **答案：** 一条 100 Mbps 电缆最多只能为 $100 / 2 = 50$ 户提供 2 Mbps 的保底下行带宽。因此对于 5000 户家庭，公司需要将社区划分为 $5000 / 50 = \mathbf{100}$ **个独立的同轴电缆网段**，每个网段连接到一个光纤节点（fiber node），同时上游骨干网络也必须具备足够的带宽容量来支撑这一保证。

11. **答案：** 约 **8193.68 秒**（约 2 小时 16 分 34 秒；按不同进制换算约为 8001.68 s 或 8591.61 s）。
    - **解析：** 1 Mbps 上行链路是瓶颈。4 段卫星链路的传播延迟约为 $4 \times 35,800 / 300,000 \approx 0.48\text{ s}$。按课件惯例（1 GB 传输时间按 $1024 \times 8 = 8192\text{ s}$ 计），加上电路建立时间 1.2 s，总时间为 $T = 1.2 + 8192 + 0.48 = 8193.68\text{ s}$。（若 1 GB 按十进制 $10^9$ 字节、速率按 $10^6$ bps 计算，约为 $8001.68\text{ s}$；若 1 GiB 按 $2^{30}$ 字节、速率按 $10^6$ bps 计算，约为 $8591.61\text{ s}$）。

12. **答案：** 约 **8595.28 秒**（若按十进制 GB 和 KB 计约为 **8005.14 秒**）。
    - **解析：** 假设文件为 1 GiB（$2^{30}$ 字节），每个分组携带 64 KiB 数据加 32 字节首部，链路速率为十进制，采用存储转发。分组数 $N = 2^{30} / (64 \times 2^{10}) = 16,384$ 个，每个分组长度 $L = (65,536 + 32) \times 8 = 524,544$ 比特。四段链路速率分别为 1、7、1、7 Mbps，包含流水线传输时间、4 段传播延迟和 3 次 10 微秒交换延迟，总时间为：
      $$T = \frac{(N+1)L}{10^6} + \frac{2L}{7\times 10^6} + \frac{4\times 35,800}{300,000} + 3\times 10^{-5} \approx 8595.28\text{ s}$$
      （若 GB 和 KB 均按十进制且 64 KB 为数据载荷，结果约为 $8005.14\text{ s}$）。
